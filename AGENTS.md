# Agent instructions
1. Before doing anything, read `PROGRESS.md` fully. It is the source of truth.
2. Verify the repo state against it (run build / lint / typecheck).
3. Continue from the "Next Step" section. Do not redo completed steps.
4. After every completed step, update `PROGRESS.md` (checkboxes, status, file map, session log) and commit.
5. Follow the design system in `docs/DESIGN.md` for all UI. Do not introduce gradients, glassmorphism, or off-palette colors.
6. Never commit `.env` or secrets.
